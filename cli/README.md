Command-line CBOR-LD processor
==============================

A (currently very crude) command-line interface to the CBOR-LD implementation in [`../lib`](../lib).

It was first developed as a way to test this implementation with the test-harness in [`../test_interop`](../test_interop),
but is expected to evolve into a full-fledged tool.

[CBOR-LD]: https://www.w3.org/TR/cbor-ld/
