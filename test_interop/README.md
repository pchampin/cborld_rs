Test harness different implementations of CBOR-LD.

Copy `example_config.toml` into `config.toml` and adapt the values:
the tools are expected to have the same command-line interface, namely:
* <tool> encode <registry_entry_id> : reads JSON-LD on stdin, and compress it as CBOR-LD on stdout
* <tool> decode : reads CBOR-LD on stdin, and decompresses it as JSON-LD on stdout

The tools are compared against all test-cases generated by `../test_factory`.

The program runs an http server (using a command line provided in `config.toml`)
serving the files in tests/ on http://localhost:8000/ .

The program accepts an optional argument which is a filter on test names.
