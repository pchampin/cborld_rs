Test-cases generator for CBOR-LD
================================

This library is a helper used by [`../lib`](../lib) and [`../test_interop`](../lib),
It procedurally creates a number of test-cases for [CBOR-LD],
in the form of pairs of files (one in JSON-LD, one in CBOR-LD).

[CBOR-LD]: https://www.w3.org/TR/cbor-ld/
